Privacy Policy

更新日期：2026年4月25日
版本：1.0

HeartBeat Memory 是一款完全本地化的 AI 日记应用。我们重视您的隐私，并承诺保护和尊重您的个人信息。本隐私政策说明了我们如何收集、使用、存储和保护您的数据。

📱 我们收集什么数据

1. 照片数据

  • 从您的相册选择照片进行分析
  • 所有照片仅在本地设备处理，不上传至任何服务器
  • 照片用于提取关键词和回忆元素

2. 位置数据

  • 仅从照片的 EXIF 信息中读取位置（如有）
  • 使用 Apple MapKit 进行逆地理编码，将坐标转换为地点名称
  • 不调用任何第三方地图 API

3. 日程数据

  • 读取您的日历事件（需授权）
  • 用于生成日记上下文
  • 数据保留在本地

🔒 数据存储与处理

  • 100% 本地处理：所有 AI 分析使用本地 LLM（MLX）
  • 本地存储：所有设置保存在 iPhone 本地（UserDefaults）
  • 不联网：可选离线模式，不发送任何数据到服务器
  • 设备端加密：受 iOS 系统数据保护

📋 数据使用目的

  • 分析照片提取回忆关键词
  • 通过逆地理编码识别地点
  • 生成个性化日记
  • 提供用户个性化设置

🚫 我们不做什么

  • 不收集任何个人信息（无需注册）
  • 不将数据上传至任何服务器
  • 不使用第三方 AI API
  • 不追踪用户行为
  • 不显示第三方广告

🔐 数据安全

  • 数据存储在 iOS 沙盒中，受系统安全保护
  • 本地 LLM 在设备内存中运行
  • 您可以随时删除所有本地数据

📖 您的权利

  • 访问权：查看本地存储的数据
  • 删除权：一键清除所有本地数据
  • 控制权：管理应用权限（照片、日历、位置）

👶 儿童隐私

本应用不面向 13 岁以下儿童，我们不会故意收集儿童个人信息。

📝 政策更新

我们可能会不时更新本隐私政策。任何重大变更将通过应用内通知告知。

📧 联系我们

如有任何隐私问题，请通过应用内反馈功能联系我们。

HeartBeat Memory is a completely local AI diary app. We value your privacy and are committed to protecting and respecting your personal information. This privacy policy explains how we collect, use, store, and protect your data.

📱 What Data We Collect

1. Photo Data

  • Select photos from your album for analysis
  • All photos are processed locally on device, never uploaded to any server
  • Photos are used to extract keywords and memory elements

2. Location Data

  • Only read location from photo EXIF data (if available)
  • Use Apple MapKit for reverse geocoding (coordinates → place names)
  • No third-party map APIs are called

3. Calendar Data

  • Read calendar events (with permission)
  • Used to generate diary context
  • Data stays on device

🔒 Data Storage & Processing

  • 100% Local Processing: All AI analysis uses local LLM (MLX)
  • Local Storage: Settings saved in iPhone (UserDefaults)
  • Offline Mode: Optional - no data sent to any server
  • Device Encryption: Protected by iOS Data Protection

📋 Data Usage Purpose

  • Analyze photos to extract memory keywords
  • Reverse geocode to identify locations
  • Generate personalized diaries
  • Provide user personalized settings

🚫 What We Don't Do

  • Don't collect personal info (no registration needed)
  • Don't upload data to any server
  • Don't use third-party AI APIs
  • Don't track user behavior
  • No third-party ads

🔐 Data Security

  • Data stored in iOS sandbox, protected by system
  • Local LLM runs in device memory
  • You can delete all local data anytime

📖 Your Rights

  • Access: View locally stored data
  • Delete: One-tap to clear all local data
  • Control: Manage app permissions (photos, calendar, location)

👶 Children's Privacy

This app is not intended for children under 13. We do not knowingly collect personal information from children.

📝 Policy Updates

We may update this privacy policy from time to time. Any material changes will be notified via the app.

📧 Contact Us

If you have any privacy questions, please contact us through the app feedback feature.
